## 👨‍💻 About Me

센서와 모터를 제어하는 코드부터
로봇의 데이터를 확인하고 명령을 보내는 앱까지 개발해 왔습니다.

최근에는 ROS 2 기반 AMR,
다중 로봇 FMS,
Zenoh 통신 구조를 중심으로 프로젝트를 진행하고 있습니다.

물류 로봇 관제 시스템입니다.

- Multi Robot Traffic Management 연구
